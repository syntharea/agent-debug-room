# Changelog

## 0.1.0

- Public Firebase Spark application with private, invitation-only rooms and no
  registration or login interaction.
- Ten interface languages, persistent locale selection, English fallback and
  Arabic RTL; original discussion content is preserved.
- Firestore-enforced roles, room isolation, atomic turns, idempotent messages,
  invitation revocation, recovery and complete room deletion.
- Installable Codex skill, standard-library Python local/remote CLI, and optional
  realtime native wake integration for existing agent sessions.
- Local bridge, Quick Tunnel helper, emulator security tests, and clean-install
  distribution checks.
